# Privacy Policy for Dispetcher Tools

**Last Updated:** October 27, 2026
**Developer:** Upgaming

## 1. Overview

Dispetcher Tools is a Chrome extension that supports dispatch-related workflows by enabling authorized functionality on supported websites.

This Privacy Policy explains what information Dispetcher Tools accesses, collects, stores, uses, and shares when you install or use the extension.

## 2. Information We Access or Collect

Depending on the features you use, Dispetcher Tools may access or process the following categories of information:

### A. Extension Settings and Preferences

The extension may store user preferences and configuration data, such as:

- extension settings
- feature toggles
- interface preferences
- saved operational options

This information is typically stored locally in the browser using Chrome extension storage.

### B. Authentication and Authorization Data

To determine whether a user is allowed to use certain extension features or access supported websites, the extension may process:

- user identifier or username
- account-related authorization or permission data
- role or access-level information
- session-related data required to verify access

This information is used only to enable or restrict functionality based on the user’s permissions.

### C. Website and Tab Information

When necessary for core extension functionality, the extension may access limited information from websites where it is enabled, including:

- the current page URL
- domain or hostname
- tab metadata
- page state needed to determine whether a supported workflow is available

The extension uses this information only to decide whether extension features should run on a given page and whether the current user is authorized to use those features.

### D. Website Content Processed for Functionality

If a feature requires interaction with a supported website, the extension may temporarily access or process page content strictly as needed to provide that feature.

Dispetcher Tools does not collect unrelated browsing activity and does not use website content for advertising, profiling, analytics, or resale.

### E. Technical and Diagnostic Information

The extension may process limited technical information necessary to maintain performance, troubleshoot failures, or protect security, such as:

- extension version
- error states
- feature execution status
- non-content diagnostic metadata

Dispetcher Tools does not use third-party analytics services unless explicitly stated in this policy.

## 3. How We Use Information

Dispetcher Tools uses the information above only for the following purposes:

- to provide the extension’s core functionality
- to determine whether a user has permission to use certain features or supported websites
- to enable, disable, or tailor features based on authorized access
- to store settings and preferences
- to maintain functionality, security, and reliability
- to troubleshoot bugs and technical issues
- to prevent unauthorized use of the extension

We do not sell user data.

We do not use user data for advertising.

We do not use user data for unrelated profiling.

## 4. Sharing of Information

We do not sell, rent, or trade user data to third parties.

We only share information in the following limited circumstances:

- with service infrastructure that we operate or use to support the extension, if required to verify authorization, permissions, or deliver the extension’s core functionality
- with service providers acting on our behalf, only where necessary to host, secure, or operate the extension-related services
- when required by law, regulation, legal process, or enforceable governmental request
- to protect rights, safety, and security, including investigation of fraud, abuse, or unauthorized access

If no server-side verification or external processing occurs for a particular feature, then that feature operates locally in the browser.

## 5. Data Storage

Dispetcher Tools may store data in one or more of the following locations, depending on the feature:

- local browser or Chrome extension storage
- temporary in-memory storage during feature execution
- secure backend systems operated by or for Upgaming, where required for authentication, authorization, or extension functionality

We retain data only for as long as reasonably necessary to provide the extension’s features, maintain security, comply with legal obligations, and resolve disputes.

## 6. Data Security

We use reasonable administrative, technical, and organizational measures designed to protect information from unauthorized access, alteration, disclosure, or destruction.

These measures may include:

- encrypted transmission where applicable
- access controls
- restricted administrative access
- secure update and maintenance practices

No method of transmission or storage is completely secure, but we take reasonable steps to protect the data we handle.

## 7. Website Permissions and Host Access

Dispetcher Tools may request Chrome permissions and host permissions in order to operate on supported websites.

These permissions are used only for the extension’s stated functionality, including:

- detecting whether a page is a supported website
- enabling extension features on approved sites
- checking whether the current user has permission to use those features
- interacting with page elements only as necessary for extension functionality

The extension does not request permissions for unrelated purposes.

## 8. Browsing Activity

Dispetcher Tools does not collect or retain browsing history except to the limited extent necessary to detect supported pages, run requested features, or verify whether functionality should be available on a given website.

The extension does not use browsing-related information for advertising, data brokerage, or unrelated tracking.

## 9. Your Choices and Rights

Depending on how the extension is used, you may be able to:

- uninstall the extension at any time
- remove locally stored extension data by clearing the extension’s storage or removing the extension
- disable the extension on specific sites
- stop use of the extension if you do not agree with this Privacy Policy
- contact us to request information about data handling

If server-side account or authorization data is involved, you may also contact us to request deletion or review, subject to legal and operational requirements.

## 10. Children

Dispetcher Tools is not intended for children under 13, and we do not knowingly collect personal information from children under 13.

## 11. Changes to This Policy

We may update this Privacy Policy from time to time. When we do, we will revise the **Last Updated** date above. Continued use of Dispetcher Tools after an update means you accept the revised policy.
